Temperatura en Sololá

Este módulo permite consultar el comportamiento térmico de los municipios del departamento de Sololá. Reúne temperatura media, máxima y mínima, rango térmico, humedad relativa, observaciones disponibles y pronósticos para facilitar el análisis de las condiciones ambientales que influyen sobre la producción agropecuaria.

La información histórica utiliza datos de NASA POWER. Los registros y productos disponibles se actualizan conforme se incorporan nuevos datos al portal.
