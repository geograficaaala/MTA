Precipitaciones

Consulta operativa de lluvia observada para el departamento de Sololá. El módulo integra datos oficiales (INSIVUMEH), estaciones locales (Vivamos Mejor) y estaciones complementarias PWS, conservando fuente, fecha de consulta, unidad, estado operativo y crédito institucional por cada registro.
