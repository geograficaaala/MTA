Atlas agroclimático

Catálogo de mapas interactivos

La plataforma debe crecer hacia muchos mapas, no una sola vista. Cada mapa tendrá fecha, fuente, crédito, tipo de dato y descarga.

Actualización diaria

Flujo interno de datos

La página pública no depende de consultar fuentes externas en vivo; consulta fuentes autorizadas diariamente, guarda evidencia y sirve datos desde la plataforma.

Consultar

Visita programada a páginas institucionales autorizadas, con registro de hora y URL.

Guardar

Copia interna temporal del HTML, imagen, PDF o tabla, manteniendo fuente y crédito.

Normalizar

Conversión a variables comunes: lluvia, temperatura, humedad, viento, riesgo y municipio.

Visualizar

Mapas clicables, gráficas tipo estación, fichas municipales y semáforos agroclimáticos.

Publicar

Boletines web, PDF, imágenes para redes y resumen para WhatsApp.
