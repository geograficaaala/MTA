Información climática

Consulta climática para el departamento de Sololá.

Esta sección reúne los módulos meteorológicos disponibles para consultar precipitación, temperatura y viento. Cada módulo permite revisar las condiciones observadas, los pronósticos y los registros disponibles para apoyar el seguimiento climático del territorio.

Información organizada por variable meteorológica.

Los módulos conservan sus herramientas de consulta y presentan la información por tema. Desde aquí puedes ingresar directamente al contenido que necesites sin recorrer secciones que no corresponden a tu consulta.

Módulos disponibles

Precipitación, temperatura y viento.

Cada módulo concentra observaciones, pronósticos, series históricas, comparaciones y visualizaciones relacionadas con una variable meteorológica específica.

Precipitación

Lluvia observada y comportamiento esperado.

Consulta la precipitación registrada, el pronóstico de lluvia, las series históricas y la distribución territorial disponible para los municipios de Sololá. El módulo permite comparar períodos y revisar el comportamiento reciente de la lluvia.

Observación meteorológica Pronóstico de precipitación Series históricas Comparación municipal
Abrir precipitación
Espacio para fotografía de precipitación

Temperatura

Condiciones térmicas y variación territorial.

Revisa temperatura media, máxima y mínima, además de pronósticos y registros históricos. El módulo facilita la comparación entre municipios y permite identificar cambios térmicos relevantes para el seguimiento climático y agropecuario.

Temperatura observada Pronóstico térmico Valores máximos y mínimos Comparación territorial
Abrir temperatura
Espacio para fotografía de condiciones térmicas

Viento

Velocidad, dirección y rachas de viento.

Explora las condiciones de viento disponibles para Sololá mediante registros observados, pronósticos y herramientas de comparación. El módulo incluye información sobre velocidad, dirección y rachas, además de productos de apoyo para interpretar sus patrones.
