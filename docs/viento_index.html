Viento en Sololá

Este módulo permite consultar la velocidad y dirección del viento en los municipios del departamento de Sololá. Reúne información histórica, observaciones disponibles, comparación territorial, dirección predominante y pronósticos para facilitar la interpretación de las condiciones atmosféricas relevantes para la actividad agropecuaria.

La información histórica utiliza datos de NASA POWER. El módulo también integra observaciones disponibles, pronóstico de Open Meteo y el mapa interactivo de Windy para complementar la consulta territorial.
