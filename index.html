Arquitectura de datos

Pipeline ETL asíncrono sobre repositorio estático con distribución vía CDN.

La plataforma opera sobre un modelo de integración continua desacoplado del cliente. Los workflows de GitHub Actions ejecutan jobs de extracción según schedules cron, serializan los registros en esquemas JSON normalizados y los persisten directamente en el repositorio. GitHub Pages sirve los archivos resultantes desde la red de distribución de Fastly sobre HTTPS, sin backend de aplicación ni base de datos relacional en la cadena de entrega.

Fetch

Extracción programada por cron

Un workflow YAML define un schedule cron que dispara el job de extracción en el runner de GitHub Actions. El script realiza peticiones HTTP a los endpoints autorizados de cada fuente: API REST de Ambient Weather (v1), portal de INSIVUMEH y endpoints de Vivamos Mejor. Las respuestas se validan contra el esquema esperado antes de continuar el pipeline.

ETL

Normalización y persistencia en repositorio

Los registros obtenidos se transforman al esquema canónico de la plataforma: station_id, timestamp_utc, variable, value, unit, source_url e institution. Los archivos actual.json y los históricos CSV se sobreescriben en docs/data/ mediante un commit automático firmado por el runner, manteniendo trazabilidad completa en el historial de Git.

CDN

Distribución estática desde GitHub Pages

GitHub Pages publica el directorio docs/ en la CDN de Fastly con certificado TLS automático. El cliente ejecuta fetch() a rutas relativas con cache-busting por querystring (?v=timestamp), eliminando cualquier intermediario de backend. La latencia de respuesta depende exclusivamente del edge node asignado por Fastly, no de un servidor de aplicación.

Post

Generación de productos derivados

Scripts de postprocesamiento consumen los archivos crudos en modo lectura para generar rankings, agregaciones estadísticas, resúmenes por municipio y estructuras de datos para visualizaciones. Los productos se escriben en rutas separadas dentro de docs/data/, preservando la integridad de los archivos de origen y permitiendo re-generación idempotente en cualquier punto del historial.
