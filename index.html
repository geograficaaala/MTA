Arquitectura de datos

La plataforma no consulta en vivo: actualiza, guarda y sirve.

El sitio se alimenta de archivos generados automáticamente. Esto hace que la página sea rápida, trazable y más resistente a fallos temporales de las fuentes.

Consulta programada

GitHub Actions visita las fuentes autorizadas de forma periódica y extrae solo la información configurada.

Almacenamiento con fuente

Cada registro se guarda con fecha, estación, institución, variable, unidad, enlace de origen y crédito.

Servicio desde la plataforma

Las páginas leen JSON y CSV internos, evitando consultar fuentes externas cada vez que alguien entra.

Productos derivados

Mapas, resúmenes, rankings y boletines se generan como productos derivados, sin alterar los datos crudos.
